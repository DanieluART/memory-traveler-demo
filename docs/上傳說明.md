# GitHub 覆蓋測試步驟

1. 解壓縮 `memory_traveler_web_demo_v51_match3_github.zip`。
2. 將資料夾內所有內容複製到目前 GitHub repository 根目錄。
3. 若原本已有正式 `assets/`，可以只覆蓋 `index.html`，避免測試用 placeholder 圖片蓋掉正式美術。
4. Commit 後 push：

```bash
git add index.html README.md CHANGELOG.md docs .nojekyll .gitignore assets
git commit -m "feat: add match3 memory collection before card battle"
git push origin main
```

5. GitHub Pages 等待部署完成後，重新整理手機瀏覽器測試。

## 測試重點

- 開頭故事是否可以進封面。
- 封面「開始遊戲」是否先進三消。
- 三消達標後是否能進入卡牌戰鬥。
- 卡牌戰鬥開場是否出現三消加成紀錄。
